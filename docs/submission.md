# Тексты для формы сдачи (ИИкузница → «Результат»)

**Демо-видео:** _ссылка на запись (до 3 мин, один дубль)_
**Репозиторий:** https://github.com/viteax/softradar
**Доп. материалы:** https://github.com/viteax/softradar/tree/main/docs (расчет стоимости, сценарий демо); отчет xlsx – https://softradar.iptvik.ru/report.xlsx
**Адрес стенда:** https://softradar.iptvik.ru

## 1. Что сделано за 48 часов и что нет

Работает и показано в видео:
- Мониторинг Росэлторга (все секции, включая «Мониторинг цен» Росатома, Росэлторг.Бизнес, 223-ФЗ) и Фабриканта
  по 18 запросам (общие формулировки закупок ПО + ключевые вендоры из задачи); автозапуск каждый час (SLA ≤ 3 ч).
- Жесткие критерии Softline кодом: ПО, НМЦ ≤ 1 млн ₽, подача КП без конкурса, не только для МСП, срок не истек.
- Чтение документов закупки (docx/doc/pdf/xlsx/rtf): запрос КП, ТЗ, проект договора.
- Агент на GigaChat (function calling) извлекает НМЦ, срок приема КП, минимальный срок действия КП, порядок
  оплаты, формат договора, наличие ТЗ, позиции и количество, риски; сам ищет товары на store.softline.ru.
- Код подбирает артикул под количество, считает КП по ценам каталога (с ограничением НМЦ), оценивает маржу,
  ставит балл 0–100 с объяснением и вердикт «подходит / частично / не подходит».
- Дашборд менеджера с приоритетами, карточка закупки с ходом работы агента, отчет xlsx, черновик КП docx
  по шаблону ПАО «Софтлайн» (без подписи и печати – на проверку менеджеру), JSON API.
- Ручной режим: вставить ссылку на закупку – агент разберет ее сразу.

Частично / не сделано:
- Подключены 2 площадки из списка (Росэлторг, Фабрикант); остальные (ГПБ, Сбер B2B, B2B-Center, Мосрег,
  Бидзаар и др.) – модулем в app/sources по тому же интерфейсу search/detail.
- Отправка отчета на почту менеджеру не подключена (нужен SMTP заказчика) – отчет на дашборде и в xlsx.
- Маржа – оценка по допущению о скидке партнера от розничной цены каталога (настраивается по вендорам);
  реальных закупочных цен Softline у нас нет.
- Часть документов площадок в архивах rar/zip не распаковывается – агент работает по остальным документам и карточке.

## 2. Подход и архитектура

Площадка → парсер (httpx2 + selectolax, только открытые страницы) → жесткие фильтры (код) → карточка и
документы (текст из docx/doc/pdf/xlsx) → агент GigaChat с инструментами read_document, search_catalog,
get_variants, submit_analysis (до 12 шагов; сам выбирает, что читать и что искать) → код: артикул под количество,
цены и НДС из каталога store.softline.ru, ограничение НМЦ, маржа, скоринг → SQLite → дашборд, xlsx, docx.

Модель решает: какие документы читать, извлечение условий из свободного текста, сопоставление позиций с товарами
каталога, риски, решение «подавать / не подавать / проверить» с причиной.
Код решает: все цифры (цены, количества, суммы, маржа, балл) и критерии отбора.
Проверка ответа: самопроверка агента (итог без поиска в каталоге возвращается агенту), ссылки на товары
сверяются с каталогом, цена берется по артикулу из каталога, позиции без артикула/с количеством вне диапазона
помечаются, «подходит на 100%» ставит код. КП – черновик, менеджер проверяет перед подачей.

## 3. Стек и модели

GigaChat Ultra (GigaChat-3-Ultra, API Сбера, function calling; поддержан и OpenAI-совместимый API cloud.ru – GigaChat-4, Pro и др.); Python 3.14, Starlette, Jinja2, httpx2, selectolax, python-docx,
openpyxl, pypdf; SQLite; Docker; GitHub Actions → ghcr.io; VPS в РФ (Ubuntu 24.04, 2 vCPU) – площадки доступны
только из РФ; HTTPS через Caddy.

## 4. Расчет стоимости эксплуатации

https://raw.githubusercontent.com/viteax/softradar/main/docs/softradar_cost.xlsx (скачивается без входа)

Модель – GigaChat Ultra: выбрана замером на одних и тех же 10 закупках (scripts/compare_models.py). Против Pro
точнее (верный продукт/количество в 6 случаях из 10, хуже – ни разу), вдвое быстрее (6,4 с против 12,1 с), меньше
вызовов (4,9 против 6,3). В среднем 17,8 тыс. входных и 0,54 тыс. выходных токенов на закупку → ≈ 1,9 ₽ за разбор
по ценам cloud.ru (коммерческий доступ к GigaChat с 01.12.2026; Ultra 3.5 ≈ GigaChat3.5-432B: 96,22 / 288,6 ₽ за
1 млн). 40 закупок в день → ≈ 2,2 тыс. ₽ LLM + ~0,5 тыс. ₽ VPS в месяц. На Pro – ≈ 1,2 ₽, на GigaChat-4-708B
(cloud.ru, сейчас бесплатно) – 0 ₽: провайдер и модель меняются в .env. Сбор, фильтры, расчеты – без LLM.
Для сравнения: ручной мониторинг 15 площадок ≈ 155 тыс. ₽ в месяц.

## 5. Запуск и поставка

Поставка: Docker-образ ghcr.io/viteax/softradar + docker-compose.yml; конфигурация – .env (ключ GigaChat или cloud.ru, модель,
площадки, запросы, лимиты, скидки по вендорам). Запуск: `cp .env.example .env && docker compose up -d`.
Стенд без логина: https://softradar.iptvik.ru

Пример запроса: на стенде вставить ссылку https://www.roseltorg.ru/procedure/ATOM27112600434 и нажать «Разобрать»
(или POST /add url=…). Ожидаемый ответ: карточка с условиями (срок действия КП ≥ 60 дней, оплата в течение
10 рабочих дней после получения лицензии – постоплата), позиция Kaspersky EDR для бизнеса Оптимальный × 110,
артикул и цена из store.softline.ru, сумма КП, маржа, балл и черновик КП docx.
API: GET /api/tenders?verdict=fit → JSON со списком подходящих закупок, условиями и строками КП.
